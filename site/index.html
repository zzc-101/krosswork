自托管 / 一人一机 / MIT

合上笔记本，
任务还在跑。

组织可自托管的云端电脑 Agent。每位成员一台远程电脑：长期工作区、独立 Worker、自己的文件和记忆。用浏览器描述要完成的工作，产物写在远端。它不操作用户自己的电脑。

01 — install

先在本机跑起来

需要 Docker Engine 和 Compose v2。第一个注册账号成为平台超级管理员。

./scripts/start-cloud.sh

工作台 localhost:8787 / 管理中心 localhost:8787/admin/

02

适合谁

  • 要把 Agent 放进自己的基础设施，而不是把工作区交给模型厂商。
  • 需要多组织、角色、企业登录和按人隔离，而不是一台电脑给所有人共用。
  • 要的是摘要、方案、表格、纪要，不是改仓库、提 PR。

03

它不是什么

  • 不是编程 Agent，没有终端 UI 或本地 CLI。
  • 不操作用户自己的电脑。关掉笔记本，远端还在干活。
  • 普通成员不填 API Key、不选模型、不配权限档位。

04 — 开箱即有

一人一机
每位成员独立 Worker 和持久 /work，不是共享磁盘上的会话。
组织治理
平台超管、组织管理员、普通成员；数据按组织切开。可接企业 OIDC。
外部才确认
工作区读写自动进行。访问或修改外部系统前，工作台会明确确认。
两种部署
单机 Docker Compose；集群用 k3s Helm，Worker 是独立 Pod。集群安装仍需在真实环境验收。

05

浏览器只连控制面

  1. 成员在工作台描述结果
  2. Java 控制面管身份、对话、模型与 Worker 生命周期
  3. 每人一台远程 Worker 执行任务
  4. 产物写在 /work，对话落在 PostgreSQL
