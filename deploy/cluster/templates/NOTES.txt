1. Install JuiceFS CSI Driver if it is not already present:

   helm repo add juicefs https://juicedata.github.io/charts/
   helm upgrade --install juicefs-csi-driver juicefs/juicefs-csi-driver -n kube-system

2. Make these images available on every k3s node (import, or set images.registry):
   {{ include "kross.image" (dict "root" . "image" .Values.images.server) }}, {{ include "kross.image" (dict "root" . "image" .Values.images.web) }}, {{ include "kross.image" (dict "root" . "image" .Values.images.worker) }}

   k3s ctr images import kross-server.tar
   k3s ctr images import kross-web.tar
   k3s ctr images import kross-worker.tar

3. Change default secrets in values before any real deployment.

4. Browse through Ingress to the web service. /internal/ is ClusterIP-only via Service server.

5. Browser uploads need a reachable S3 URL. Enable rustfs.ingress with its own host,
   or port-forward: kubectl -n {{ include "kross.namespace" . }} port-forward svc/rustfs 9000:9000
   Current APP_S3_PUBLIC_ENDPOINT={{ include "kross.s3PublicEndpoint" . }}
